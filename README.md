# Ben McAvoy

I’m a Software Development T Level student with industry experience at Yunex Traffic and J.P. Morgan, including embedded firmware in C, embedded Linux and software development in engineering teams.

Outside work and education, I build software from the ground up. I’m especially interested in systems programming, embedded development, Linux, game engines, virtual machines and developer tooling.

## Open-source contribution

I reported a denial-of-service issue in Google’s Android Emulator Hypervisor Driver and proposed a checked-copy fix upstream. The [issue](https://github.com/google/android-emulator-hypervisor-driver/issues/101) and [pull request](https://github.com/google/android-emulator-hypervisor-driver/pull/102) are public; the PR is open.

## Featured projects

### [Taskbulb](https://github.com/BenMcAvoy/Taskbulb)

A Rust Windows system tray app for controlling Home Assistant lights and monitor brightness.

### [ApprenticeshipTracker](https://github.com/BenMcAvoy/ApprenticeshipTracker)

A self-hosted apprenticeship vacancy tracker with role filters, employer grouping and application tracking, plus optional CV tailoring.

### [LunaticEngine](https://github.com/BenMcAvoy/LunaticEngine)

A C++20 2D game engine and editor with OpenGL rendering, ImGui tooling, LuaJIT scripting, RTTR reflection and JSON scene serialization.

### [StrawberryVM](https://github.com/BenMcAvoy/StrawberryVM)

A Rust fantasy computer with a custom instruction set, assembler, runner and interactive REPL.

### [jellyOS](https://github.com/BenMcAvoy/jellyOS)

An experimental Rust operating system for x86_64 BIOS, with interrupt handling, keyboard input and kernel tests.

### [Rivet](https://github.com/ReDoIngMods/Rivet)

A native C++ mod loader for Scrap Mechanic that discovers Thunderstore packages, resolves dependencies and loads mod entrypoints.
